# 專案招募說明

## 🎯 我們在尋找什麼樣的夥伴？

台灣不義遺址故事地圖專案正在招募熱情的夥伴！無論你是工程師、設計師、歷史研究者，還是對這段歷史有興趣的朋友，都歡迎加入我們。

---

## 👥 招募職位

### 🖥️ 前端工程師（1-2人）

**你將負責：**
- 開發互動式地圖介面
- 實作故事瀏覽功能
- 優化使用者體驗
- 確保跨裝置相容性

**我們希望你：**
- 熟悉 React 或其他前端框架
- 了解 TypeScript（或願意學習）
- 對地圖應用有興趣
- 重視使用者體驗

**加分項目：**
- 有 Leaflet 或其他地圖套件經驗
- 了解響應式設計

**時間投入：** 每週 5-10 小時

## ❓ 常見問題

### Q1: 我沒有相關經驗，可以參加嗎？
**A:** 當然可以！我們歡迎新手，會提供必要的指導和學習資源。重要的是你的熱忱和學習意願。

### Q2: 這是有薪工作嗎？
**A:** 目前是志願性質的專案。未來如有獲得補助或贊助，會考慮提供車馬費或津貼。

### Q3: 需要投入多少時間？
**A:** 依職位不同，每週 3-10 小時不等。時間彈性，可以配合你的課業或工作。

### Q4: 可以遠端參與嗎？
**A:** 大部分職位都可以遠端參與！除了田野調查需要實地踏查外，其他都可線上協作。

### Q5: 我住在外縣市，可以參加嗎？
**A:** 完全沒問題！而且我們特別需要外縣市的夥伴，幫忙調查當地的不義遺址。

### Q6: 需要長期參與嗎？
**A:** 我們希望你能持續參與，但可以根據個人情況彈性調整。短期協助也很歡迎！

### Q7: 我可以同時擔任多個角色嗎？
**A:** 可以！如果你有多項技能且時間允許，歡迎跨職位協助。

### Q8: 如何確保我的貢獻被認可？
**A:** 所有貢獻者的名字都會列在網站上。你也可以在履歷中列出這段經驗。
