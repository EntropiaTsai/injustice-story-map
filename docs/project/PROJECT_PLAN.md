# 台灣不義遺址故事地圖 - 專案計畫書

## 📋 專案概述

### 專案願景
透過互動式地圖，讓人們發現並了解自己家鄉的白色恐怖歷史故事，促進轉型正義教育，讓這些珍貴的記憶不被遺忘。

### 專案目標
1. 建立一個易於使用的互動式網頁地圖
2. 蒐集並呈現至少 50 個不義遺址的故事
3. 提供多媒體內容（文字、圖片、影音、口述歷史）
4. 建立開放式平台，讓民眾可以貢獻故事
5. 推廣轉型正義教育，提升歷史意識

### 目標使用者
- 一般民眾（想了解家鄉歷史）
- 學生（進行歷史研究或報告）
- 教師（作為教學資源）
- 研究者（轉型正義、歷史研究）
- 受難者家屬（紀念與傳承）
