# 如何加入 YouTube 影片到故事中

## 📺 YouTube 影片功能

專案現在支援嵌入 YouTube 影片，特別適合用來展示：
- 受難者家屬的專訪影片
- 紀錄片片段
- 口述歷史影片
- 遺址導覽影片

---

## 🎬 如何取得 YouTube 影片 ID

### 方法一：從網址取得

YouTube 影片網址格式：
```
https://www.youtube.com/watch?v=dQw4w9WgXcQ
                                 ^^^^^^^^^^^
                                 這就是影片 ID
```

### 方法二：從分享連結取得

短網址格式：
```
https://youtu.be/dQw4w9WgXcQ
                 ^^^^^^^^^^^
                 這就是影片 ID
```

---

## 📝 如何加入影片到故事資料

編輯 `src/data/stories.ts`，在故事物件中加入 `youtubeVideos` 欄位：

```typescript
{
  id: '1',
  name: '岡山長老教會',
  victimName: '蕭朝金牧師',
  lat: 22.7967,
  lng: 120.2947,
  year: '1950年代',
  title: '岡山長老教會的記憶',
  summary: '蕭朝金牧師的故事...',
  content: `完整的故事內容...`,
  
  // 加入 YouTube 影片
  youtubeVideos: [
    {
      id: 'YOUTUBE_VIDEO_ID',           // 必填：YouTube 影片 ID
      title: '蕭朝金牧師女兒專訪',        // 必填：影片標題
      description: '民報採訪蕭朝金牧師的女兒，回憶父親受難經過', // 選填：影片說明
    },
    // 可以加入多個影片
    {
      id: 'ANOTHER_VIDEO_ID',
      title: '另一部相關影片',
      description: '影片說明...',
    },
  ],
  
  tags: ['白色恐怖', '高雄市', '教會'],
}
```

## 🎯 實際範例

### 範例一：民報專訪影片

```typescript
{
  id: 'kaohsiung-001',
  name: '岡山長老教會',
  victimName: '蕭朝金牧師',
  lat: 22.7967,
  lng: 120.2947,
  year: '1950',
  title: '信仰的見證者',
  summary: '蕭朝金牧師因信仰與正義感，在白色恐怖時期遭受迫害。',
  content: `（完整故事內容）`,
  
  youtubeVideos: [
    {
      id: 'YOUR_VIDEO_ID',  // 替換成實際的影片 ID
      title: '【民報專訪】蕭朝金牧師女兒回憶父親受難經過',
      description: '蕭牧師的女兒接受民報採訪，談及父親在白色恐怖時期的遭遇以及對家庭的影響。',
    },
  ],
  
  relatedLinks: [
    {
      title: '民報專訪報導全文',
      url: 'https://www.peoplenews.tw/...',  // 報導連結
    },
  ],
  
  tags: ['白色恐怖', '高雄市', '岡山', '長老教會', '信仰'],
}
```

### 範例二：多個影片

```typescript

      id: 'VIDEO_ID_1',

      description: '實地走訪歷史現場',
```

## 📋 欄位說明

### `youtubeVideos` 陣列（可選）

| 欄位 | 類型 | 必填 | 說明 |
|------|------|------|------|
| `id` | string | ✅ 是 | YouTube 影片 ID |
| `title` | string | ✅ 是 | 影片標題 |
| `description` | string | ⚠️ 選填 | 影片說明或簡介 |

---

## ⚠️ 注意事項

### 1. 版權與授權
- 確認影片可以嵌入使用
- 如果是自己上傳的影片，請設定為「允許嵌入」
- 尊重影片創作者的權利

### 2. 隱私權
- 如果影片中有受難者家屬，請先取得同意
- 確認家屬願意公開分享

### 3. 影片品質
- 選擇音質、畫質良好的影片
- 確保內容真實、客觀

### 4. 影片 ID 格式
- 只需要 ID 部分，不要整個網址
- 正確：`dQw4w9WgXcQ`
- 錯誤：`https://www.youtube.com/watch?v=dQw4w9WgXcQ`

## 🔧 測試步驟

1. **加入影片資料** - 編輯 `src/data/stories.ts`
2. **儲存檔案** - 開發伺服器會自動重新載入
3. **開啟網站** - http://localhost:5173
4. **點擊故事標記** - 開啟故事詳情
5. **檢查影片** - 確認影片可以正常播放
