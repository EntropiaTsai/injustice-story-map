# 故事蒐集指南

這份文件提供給**內容蒐集組**的成員，說明如何蒐集、整理和提交不義遺址的故事。

---

## 📚 什麼是「不義遺址」？

根據促進轉型正義委員會的定義，不義遺址是指：
- 威權統治時期，統治者大規模侵害人權事件的發生地
- 包括：監禁、刑求、審判、處決等場所
- 也包括：埋葬地、紀念地等相關場所

---

## 🎯 故事蒐集原則

### 1. 歷史真實性
- 確保故事有歷史依據
- 引用可靠的資料來源
- 避免道聽塗說或未經證實的傳聞
- 如有爭議，應註明不同觀點

### 2. 尊重當事人
- 尊重受難者及其家屬
- 敏感內容應謹慎處理
- 訪談前應取得同意
- 保護個人隱私（如當事人要求）

### 3. 平衡觀點
- 盡可能呈現完整脈絡
- 避免過度情緒化或煽動性的語言
- 讓事實說話

### 4. 在地連結
- 強調地點與當地的關係
- 記錄現況與歷史的對比
- 讓讀者感受「這就在我家附近」

## 📝 故事內容結構

每個故事應包含以下資訊：

### 必要欄位

#### 1. 基本資訊
```yaml
ID: 唯一識別碼（例如：TPE-001）
地點名稱: 正式名稱或俗稱
受難者姓名: 主要受難者（可多位）
地理位置:
  - 經度: XX.XXXX
  - 緯度: XX.XXXX
  - 地址: 詳細地址
時間: YYYY 或 YYYY-YYYY
```

#### 2. 故事標題
- 簡短有力（建議 10 字以內）
- 能引起興趣
- 避免過於驚悚

#### 3. 摘要（100-150字）
- 一段話說明這個地點的歷史意義
- 吸引讀者想了解更多

#### 4. 完整內容（500-1500字）
應包含：
- **歷史背景**：事件發生的時空背景
- **事件經過**：發生了什麼事？
- **受難者故事**：當事人的經歷
- **歷史意義**：這個事件的重要性
- **現況**：這個地點現在的樣子

寫作建議：
- 使用說故事的方式，不要只是條列事實
- 加入細節讓故事更生動
- 但避免虛構或過度渲染
- 使用淺顯易懂的文字

#### 5. 標籤（3-5個）
例如：白色恐怖、台北市、監獄、刑場、紀念公園、學生運動

### 選填欄位

#### 6. 多媒體素材
- **照片**：現場照片、歷史照片、受難者照片
- **影片**：紀錄片、訪談影片、空拍影像
- **音訊**：口述歷史錄音、導覽音訊

#### 7. 延伸資料
- **相關連結**：相關報導、研究論文、官方資料
- **參考書目**：引用的書籍、檔案
- **相關人物**：其他受難者、重要歷史人物
- **相關地點**：附近的其他不義遺址

## 🎤 訪談指南

### 訪談前準備

1. **背景研究**
   - 先查閱相關資料
   - 準備訪談大綱
   - 準備錄音設備

2. **聯繫受訪者**
   - 說明專案目的
   - 取得訪談同意
   - 約定時間地點

3. **準備器材**
   - 錄音筆或手機（確保有足夠電力和儲存空間）
   - 相機（如需拍照）
   - 筆記本
   - 同意書

### 訪談過程

1. **開場**
   - 再次說明專案目的
   - 簽署同意書
   - 說明錄音與使用方式

2. **訪談技巧**
   - 使用開放式問題
   - 認真傾聽，不要打斷
   - 適時追問細節
   - 保持同理心
   - 注意受訪者情緒

3. **建議問題**
   - 可以請您說說那段經歷嗎？
   - 當時的情況是怎樣的？
   - 您還記得哪些細節嗎？
   - 這件事對您/家人有什麼影響？
   - 您希望年輕人知道什麼？

4. **敏感議題處理**
   - 如受訪者不願談，不要強求
   - 給予充分的時間和空間
   - 必要時暫停或改天再談

### 訪談後處理

1. **整理逐字稿**
   - 盡快完成（記憶猶新）
   - 標註時間碼
   - 標註不清楚的地方

2. **確認內容**
   - 可將逐字稿給受訪者確認
   - 確認可公開的內容
   - 確認署名方式

3. **保存檔案**
   - 原始錄音檔妥善保存
   - 備份到雲端
   - 標註清楚的檔案名稱

## 📷 影像拍攝指南

### 現場拍攝

#### 應拍攝的內容
- 遺址全景
- 重要特徵（建築、紀念碑等）
- 細節（碑文、門牌等）
- 環境與周邊

#### 拍攝技巧
- 多角度拍攝
- 注意光線
- 拍攝高解析度照片
- 如有紀念碑或說明牌，確保文字清晰

#### 注意事項
- 尊重現場（不要破壞或擅入）
- 注意安全
- 如需進入私人場所，應先取得同意

### 歷史照片蒐集

#### 來源
- 國家檔案局
- 家屬提供
- 歷史照片資料庫

#### 版權問題
- 確認使用授權
- 註明照片來源
- 取得家屬同意

## 📤 提交流程

### 1. 準備資料
將蒐集到的資料整理成以下格式：

```
故事資料夾/
├── story.md（故事內容）
├── images/（照片資料夾）
│   ├── 01_全景.jpg
│   ├── 02_紀念碑.jpg
│   └── ...
├── videos/（影片資料夾，如有）
├── audios/（音訊資料夾，如有）
└── references.md（參考資料清單）
```

### 2. 提交方式

#### 方式一：GitHub（推薦）
1. Fork 專案
2. 在 `/data/stories/` 目錄下新增資料夾
3. 提交 Pull Request

#### 方式二：Email
將整理好的資料夾壓縮後，寄送至專案信箱

#### 方式三：雲端連結
將資料上傳至 Google Drive 或 Dropbox，分享連結

### 3. 審核流程
1. 內容編輯組收到投稿
2. 進行事實查核
3. 文字編輯與調整
4. 與投稿者確認修改內容
5. 上架發布

## 💡 常見問題

### Q1: 如果找不到確切的經緯度怎麼辦？
A: 可以使用 Google Maps 找到地點後，在地圖上點擊右鍵選擇「這是哪裡？」就會顯示座標。

### Q2: 如果受難者不願意公開姓名？
A: 可以使用化名，並在內容中註明「為尊重當事人意願，使用化名」。

### Q3: 如果故事資料不完整怎麼辦？
A: 沒關係！可以先提交現有資料，註明「資料持續蒐集中」，之後再補充。

### Q4: 可以寫自己家鄉的故事嗎？
A: 當然可以！這正是專案的初衷。只要確保資料可靠即可。

### Q5: 需要專業歷史背景才能參與嗎？
A: 不需要！只要對這段歷史有興趣，願意認真蒐集資料，任何人都可以參與。
